## 2. 用户可见变化（按页面）

- **左栏**：纯图标 + tooltip，默认不显示文字；设置「显示导航文字」可打开（D2）。内容组：主页 / 任务 /
  更新 / 错误 / 文件 / 分享（占位），底部：设置 / 帮助 / 诊断。
- **顶栏**：只有 24px 页面标题 + 一行安静连接状态（主机 · 已连接/未配置）；右上角 NAS 图标菜单
  （添加 / 管理 / 连接测试）。pid/uptime/socket/启停/登录全部收进「诊断 → 运行控制」。
- **主页/任务**：官方式平铺任务卡（状态圆、名称、`Sync` 角标、上次同步绝对时间、暂停 / ⋮ / ›）；
  单连接不出分组标题；点击进详情页（本地/NAS 双卡、一对一文件夹对表、同步设置键值）。
- **创建任务**：先选类型 → 同步任务表单模态；备份任务置灰并说明不做；ID/路径/缓存/方向收进「高级」折叠。
- **文件更新中心**：文件 / 活动 / 时间 / 说明四列；来源连接行内徽标；时间/活动排序、搜索、活动筛选、
  清除筛选；活动名去技术（原始 kind 在 tooltip）。
- **错误列表**：独立页、按任务分组；行操作「定位 / 复制路径 / 日志」；连接级错误单独一组。
- **文件**：目录表列对齐（名称/类型/大小/修改时间/状态/操作）；状态三态 + 同步维度压成单图标 + tooltip；
  pin 英文 key 收进 ⋯ 菜单；搜索页保留。
- **设置**：4 个 tab（代理 / 个人 / 高级 / 释放空间）；同步筛选、日志轮转、LAN 收进「高级」折叠；
  危险区留「高级」底部；个人语言/地区改下拉。
- **帮助/关于**：左栏 ⓘ 打开；关于只留版本/许可/运行概览（路径类信息在诊断）；
  含快速入门、新增功能、开源声明、在线文档。
- **分享**：诚实占位（说明无 Qsync Central 分享 API + File Station 深链）。
- **首次引导**：无连接新用户首次启动三步引导，可跳过。
- **托盘**：打开主窗口 / 立即同步 / 暂停 / 设置 / 关于 / 退出。

## 4. 诚实性边界（不改语义、不造数据）

- 「始终可用」= `pin=pinned`，不等于「内容已在本地」；状态列 tooltip 同时给空间三态与同步状态。
- 「立即同步」= 触发一轮轮询，不是强制全量扫描；没有百分比进度就不画进度条。
- 暂停 = 卸载挂载点（后端语义），UI 文案按暂停展示。
- LAN 同步是 qxync 自研协议，与官方 Windows 客户端不互通；界面明确写「同一账号的 qxync 设备」。
- 自动更新置灰：从源码分发，没有更新通道；不做一个点了没反应的开关。
