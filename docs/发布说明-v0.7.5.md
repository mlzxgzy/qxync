# v0.7.5 —— 断网不再刷屏报错 + 托盘三色状态点（M28）

> 发布日期：2026-10-21
> 上一版：[v0.7.4](发布说明-v0.7.4.md)（Dolphin 删除不再报「无法写入文件 …trashinfo」）
>
> **体验版**：三件事 —— ① 断网/网络波动**不再弹窗、不再进错误列表**，
> 一次断网只记一条（先探活确认，真断才报，闪断静默）；② 连接状态改由
> **托盘图标右下角的状态点**表达：🟢 正常 / 🔴 断网 / 🟡 有错误；
> ③ 同步产生新冲突时弹一条桌面通知。另含 Dolphin 角标插件的 deb 分发
> （kf5/kf6 双包，盖 Debian 12/13 + Ubuntu 22.04/24.04/26.04）。

**升级就是换二进制 + 重启 daemon**（`systemctl --user reload qxyncd` 可不断挂载点）。
GUI 换新后托盘点即生效。设置文件零迁移。

## 一句话

以前一次拔网线：一轮轮询里 `qbox_get_sync_log`、`qbox_get_device_config_list`、
`qbox_query_notify`、对账的**每个目录**各报一条错，每条还要各等一次 connect
timeout，桌面通知弹「同步出错」，错误列表被同一件事刷满 —— 用户看到的是
「程序到处报错」，事实只有一句「网断了」。v0.7.5 把它整个翻过来：

```text
断网   ：托盘点变红，不弹窗、错误列表干净 —— 本地改动先攒着，联网自动续
网络抖 ：探活确认 NAS 还在 → 静默继续（每轮最多 3 条网络类记录，其余 debug）
有错误 ：托盘点变黄（如 CGI 500、删除熔断）—— 这才是该看一眼的
新冲突 ：弹一条「qxync 发现同步冲突」桌面通知
```

## 〇、怎么用（都不用开开关）

```text
托盘状态点：全自动。
  🟢 绿点  所有运行中的连接全部正常
  🔴 红点  探活确认网络断（离线缓冲区在攒改动）
  🟡 黄点  网络通着但有错误（CGI 500 / WAF 403 / 删除熔断）
  无点    没有 daemon 在跑（自己没配任务不是故障，不误报）

鼠标悬停托盘：tooltip 跟状态走（「在线」/「离线：连接X」/「注意：…」）

断网时写文件：照常 —— 离线缓冲区（M20/M21）攒着，联网后自动回放
诊断网络问题：journal 页 → 筛选「警告（网络）」；或 qxync status 看 connectivity
```

## 一、降噪：网络错误从「错误」降为「警告」

| 层 | 行为 |
|---|---|
| daemon | 网络类错误写 journal 时降级 `warn`（`kind=network`）—— 桌面通知与错误列表**天然查不到** |
| 判据 | 结构化标记 `SyncReport.error_is_network`（与 errors 逐条对齐、含 20 条截断），不是事后从文本猜 |
| 老 daemon | 前端按文案兜底识别（「网络不可用」/「网络错误」开头），升级 GUI 不弹旧 daemon 的网络窗 |
| 首页/任务卡 | 离线横幅显示时不再叠「同步出错」红字；任务卡改「网络断开 —— 本地改动先攒着，联网后自动同步」 |
| 诊断不丢 | journal 页新增「警告（网络）」筛选项；`status.connectivity.last_error` 保留 |

## 二、先探活再报错（v0.7.5 的同步引擎侧）

任何一步遇到**网络层**错误，先花 5 秒探一次 NAS（`Client::probe_network`，不需要会话）：

- **探活也失败** = 整台不可达 → 立刻中止本轮，只记一条（NAS 地址 + 做到哪一步 +
  恢复后自动继续），跳过其余视图与待裁决巡检；中止轮次不清上一轮的真实告警
- **探活通过** = 单条请求被丢（闪断）→ 继续本轮；网络类错误整轮最多记 3 条
  （事件与对账共用一份配额），其余降 debug
- **探活结论带失效期**（10 秒）且连续 3 次网络失败强制重探 —— 弱网下探活侥幸
  通过、随后链路恶化时，最坏一分钟内重新确认并中止，不会拿一个 `true` 把
  上千条事件逐条等超时跑完
- **连通性按探活结论判定**：CGI 持续 500 / WAF 403 / NAS 封 IP 这类「HTTP 有
  回应」的故障不再被误判成断网而长期冻结上传/删除队列
- **事件游标只推进到已完整应用的那一批**：批中途断网，当前批下一轮整批重放，
  安全性靠 `apply_event`/`apply_decision` 的幂等性（回归用例钉住，重放不删东西、
  不产生第二个冲突副本）
- 离线恢复探活退避：刚断 3 秒一轮（拔网线 5 秒仍秒级恢复），30 秒后 10 秒、
  5 分钟后 30 秒（关机一整夜的 NAS 不再被当压力测试）

## 三、托盘三色（实现要点）

- 状态点画在图标右下角（带描边，深浅色托盘都可见），品牌形状不动；三个变体
  编译期 `include_bytes!` 进二进制，不依赖运行时资源文件
- 前端 2s 轮询 `refreshStatus` 后聚合所有连接，**仅在状态变化时**调 `tray_set_status`
  —— SNI 换图标是 D-Bus 往返，无脑重设会刷总线
- 多连接聚合优先级：红 > 黄 > 绿；没有运行中的连接保持原图标
- 托盘失败只记日志不拖垮 GUI（沿用 M8.4 原则）

## 四、冲突弹窗

- 发现新的「双方都改」冲突 journal 条目 → 桌面通知「qxync 发现同步冲突（连接X）」，
  正文引导打开主窗口处理（任务页有待裁决队列）
- 待裁决队列的自动清理不算新冲突，不弹；尊重「桌面通知」设置；与错误检查共用
  6s tick、去重键独立

## 五、Dolphin 角标插件 deb 分发（kf5 / kf6）

Debian / Ubuntu 矩阵横跨 KF5 / KF6 两代（Debian 12 / Ubuntu 22.04 / 24.04 的
Dolphin 是 KF5，Debian 13 / Ubuntu 26.04 是 KF6），插件 `.so` 的 ABI 绑 KIO
大版本。发版流水线新增两个资产：

```text
qxync-dolphin-overlay-kf5_<版本>-1_amd64.deb   （ubuntu:22.04 基线编）
qxync-dolphin-overlay-kf6_<版本>-1_amd64.deb   （debian:13 基线编）
```

KF 系列内向后兼容，两包合盖五个发行版；CI 每次发版在五个容器里实装校验。
插件源码 Qt5/Qt6 双兼容（`KOverlayIconPlugin` 同一接口，CMake 按
`-DQXYNC_KF_MAJOR` 分支）。Arch 包照旧（`pacman -U`）。
