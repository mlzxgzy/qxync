**P0 执行中的三点偏离（已记录，非缩水）**

1. **左栏内容组是 5 个不是 4 个**（主页/任务/更新/错误/文件）：官方 4 个里「任务列表」对应 qxync 主页+任务，
   「文件」是 qxync 自有目的地；P3-01/02 加分享/帮助后会变成 6。设置/诊断按官方习惯压底部。
2. **当前连接下拉落到「诊断 → 运行控制」**，不是设置页：它跟启停/登录是同一组排障动作；P2-10 再做右上角
   连接菜单，把日常切换放回一手位置。
3. **顶栏右侧操作区留到 P1**（Add/齿轮）：P0 先把「运维控制台」拆干净、标题与连接行立住；任务页重做时
   再加真正的页面级动作，避免现在做一遍又要挪。

**P1 批次的三个实现口径**

1. **任务详情是二级页，不用模态**：与官方一致（`↩ 任务 / 标题`，左栏不新增项）；`QXNYC_GUI_TAB=task:<id>`
   只是验收/深链入口，正常用户从卡片 `›` 或双击进入。
2. **卡片保留 ⋮ 菜单**：官方卡片只有暂停 + `›`；qxync 的删除/同步设置是低频但必须可达，折中为
   「暂停 + ⋮ + ›」——⋮ 与详情页右上角共用同一个 `#task-menu`，删除仍走三次确认（新增「仅删任务登记」出口）。
3. **P1-03 的「进度 N/M」没做**：daemon 的 `sync` 快照只有计数没有字节/条目进度，编一个进度条就是假数据；
   卡片次行只放**能证明的**绝对时间（由 `last_sync_ok_age_secs` 现算），进度等后端给数据再加。
4. **创建表单 = 文件夹对设置**：P1-09 的「创建同步任务」与 P1-13 的「文件夹对设置」共用同一个模态
   （标题按 create/edit 切换），避免两份字段漂移；P1-14 的高级折叠也在同一表单里。

**顺手修掉的一个验收陷阱**：`ui/*` 是编译期嵌入，但 proc-macro 读文件不在 cargo 依赖图里 ——
只改 `app.js`/`style.css` 再 `cargo build` 不会重嵌，截图看到的是上一版（本次调试踩到）。
`crates/qxync-gui/build.rs` 已登记 `ui/*` 为 `rerun-if-changed`；`gui-matrix.sh` 也改成按
`Xft.dpi` 自动换算 `GDK_DPI_SCALE=96/dpi`，以后每个批次截图都是 1× 基线。
