# v0.6.3 —— 任务默认路径 + 删除相关数据

> 发布日期：2026-10-18
> 上一版：[v0.6.2](../docs/发布说明-v0.6.2.md)（两步验证 / TOTP）
>
> 本版包含两个里程碑：**M18 任务默认路径** 与 **M19 删除相关数据**。

---

## 亮点

### 1. 新建任务的 id / 本地文件夹 / 水合缓存不再撞车（M18）

以前新建任务时，三处默认值对所有任务都一样：任务 id 固定 `default`、本地文件夹固定
`~/qxync-mnt`、水合缓存按连接共享。第二条任务一提交就撞 id 或撞挂载点，只能手改三格。

现在按 **「连接 + NAS 文件夹」** 派生，天然唯一：

| 字段 | 默认值 | 例子（连接 `default`、NAS 选 `/home`） |
|---|---|---|
| 任务 id | NAS 文件夹名（重名自动 `-2` / `-3`） | `home` / `home-2` |
| 本地文件夹 | `~/qxync/<连接 id>/<任务 id>` | `~/qxync/default/home` |
| 水合缓存 | `<data_dir>/cache/tasks/<连接 id>/<任务 id>`（父目录） | `~/.local/share/qxync/cache/tasks/default/home` |

* 表单先选 NAS 文件夹，id 与两条路径跟着变；**手改过的字段不会被自动覆盖**
  （「重置为默认路径」可恢复）；编辑已有任务不做派生。
* 新建时拦下「id 为空 / 非法 / 已被别的任务占用」，不再静默覆盖另一条任务。
* **已保存任务的路径一个都不动**，任务文件格式没有新增字段（回退旧版本无影响）。

详见 [`M18-任务默认路径.md`](M18-任务默认路径.md)。

### 2. 删除相关数据：任务 / 连接 / 本机全部（M19）

以前「删除任务登记」「移除连接」只删登记，水合缓存、`sync/<ns>`（baseline / 日志 /
待裁决）、`upload-queue/<ns>`、日志会永远留在本机。现在三级都能把相关数据一起删：

| 作用域 | 删什么 |
|---|---|
| **任务** | 登记 + 该任务水合缓存 + baseline / journal / decisions 里落在该 NAS 文件夹子树的**行** |
| **连接** | 任务登记 + link / 凭据 / peers + `sync/<ns>` + `cache/<ns>` + `upload-queue/<ns>` + 挂载记录 + 该连接日志 + socket / pid |
| **本机全部** | 配置 / 数据 / 状态三个根（恢复出厂），会先停掉所有 daemon |

**安全边界（任何作用域都一样）**：

* **不删 NAS 数据、不删挂载点里的文件**；
* 共用缓存 / 共用 NAS 文件夹不猜，跳过并警告；
* 符号链接只删链接本身；
* 先给计划（会删什么 / 多大 / 多少状态库行），GUI 弹窗确认、CLI 默认只预览；
* 复选框默认不勾选 —— 不勾就是旧行为（只删登记）。

**怎么用**：

* GUI：任务卡「**删除…**」、连接行「**移除**」、设置 → 高级 → **危险区**（必须勾选才可确认）。
* CLI：
  ```bash
  qxync purge --task home                 # 预览（默认）
  qxync purge --task home --yes           # 真删任务 + 缓存 + 状态库行
  qxync --link nas2 purge --connection --yes   # 删这条连接的全部本地数据
  qxync purge --all --yes                 # 恢复出厂（先停所有 daemon）
  ```

详见 [`M19-删除相关数据.md`](M19-删除相关数据.md)。

## 已知边界

* GUI 目前只有「全部相关数据」一个开关（没有逐项勾选）。
* 任务级 purge 不动按连接共享的上传 / 删除队列、`pins`、`nodes`（可重建 / 无任务归属）。
* 删完会留下空的父目录（如 `cache/tasks/default/home/`），`--all` 会清整个根。
* 全局 purge 不删系统 autostart 项（到「设置 → 高级」关）。
* 以下功能仍与官方 Windows 客户端不同：不做缩略图 / 备份任务 / 以前版本还原 / 团队文件夹；
  **141/313 个后端端点本环境无路由**（前端比后端新的既有事实，与本版无关）。
