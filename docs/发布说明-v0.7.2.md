# v0.7.2 —— Dolphin 角标开关：文件图标上的彩色水合状态（M24）

> 发布日期：2026-10-20
> 上一版：[v0.7.1](发布说明-v0.7.1.md)（水合状态进 Tags 列）
>
> **功能版**：KDE / Dolphin 用户在**文件图标上**直接看到水合状态 ——
> 绿对钩 = 已水合、蓝云 = 仅在线、半满圆 = 部分本地，和 Windows 资源管理器 /
> CFA（Cloud Files API）同一种表达。用**独立开关**控制（默认关），与 Tags 列
> 开关互不影响。真机验证全绿。

**升级就是换二进制 + 重启 daemon**（`systemctl --user reload qxyncd` 可不断挂载点）。

## 一句话

v0.7.1 的水合状态只能在 Dolphin 的 Tags 列里看文字/字符 —— 用户实测反馈
「标签没有颜色，看也看不太出来」。v0.7.2 补上真正的**图标**：一个
`KOverlayIconPlugin` 插件在文件图标左下角画彩色角标；同时把「角标」做成与
「Tags 列」**独立的开关**（默认都关），因为角标只有 Dolphin 支持（KDE 的
`KOverlayIconPlugin` 接口），别的文件管理器不认。

## 〇、怎么用（三步）

```text
1. 装角标插件（只支持 KF6 Dolphin；装完重启 Dolphin）
   系统级（推荐，无需环境变量）：
     cd contrib/dolphin/overlay
     cmake -S . -B build -DCMAKE_BUILD_TYPE=Release && cmake --build build -j
     sudo cmake --install build --prefix /usr
2. 打开开关：GUI 设置 → 高级 →「在文件图标上显示状态角标」
   （与「在 Dolphin 里显示水合状态（Tags 列）」是两个独立开关，可只开一个）
3. 挂载点须已排除出 Baloo 索引（与 Tags 列同一前置条件，GUI 会弹终端一键排除）
```

只看 Tags 列、不装插件的人完全可以不装 —— 插件是可选组件（`contrib/`，不参与
cargo 构建，也不在 release 产物里）。

## 一、为什么是「角标 + 开关」

* Dolphin **没有**「插件往列表里加一列」的接口（列是写死的），Tags 列只能显示
  文字/字符，字色跟正文一样；
* Dolphin 唯一开放的图标化机制是 `KOverlayIconPlugin`：插件按 URL 返回图标名，
  Dolphin 用 `QIcon::fromTheme()` 画在文件图标的左下 / 右上 / 右下角（最多 3 个，
  左上角固定留给 VCS 插件）。这正是资源管理器 / CFA 那套；
* 它**只在 Dolphin（KDE）里生效**：Nautilus / Thunar 各有自己的扩展机制，本版本
  没有做；`user.xdg.tags` 本身是 freedesktop 标准，任何工具都能读，但只有
  Dolphin 的 Tags 列会显示它。
* 所以角标做成开关（默认关）：不装插件、不用 Dolphin 的人完全无感；开关关着时
  FUSE 连 `user.qxync.overlay` 这个属性都不会出现在名单里。

## 二、两条通道对比

| | Tags 列（M23，v0.7.1） | 文件图标角标（M24，本版） |
|---|---|---|
| 开关 | `settings.dolphin_tags`（默认关） | `settings.dolphin_overlay`（默认关） |
| xattr | `user.xdg.tags` = `✓` / `☁` / `◐` | `user.qxync.overlay` = `placeholder` / `partial` / `hydrated` |
| 显示 | Dolphin 自带 Tags 列（文字/字符） | 插件在文件图标左下角画彩色角标 |
| 需要插件 | 不需要 | 需要（`contrib/dolphin/overlay`） |
| 前置条件 | 挂载点排除出 Baloo 索引 | 同左 |
| 刷新 | F5 / 重进目录 | 同左 |

两个开关**相互独立**：只开 Tags 列 = v0.7.1 的行为；只开角标 = 文件图标上有
图标、Tags 列不写；两个都开 = 两者同时生效；都关 = 与 v0.7.1 之前完全一致。

## 三、开关语义

| 方面 | 行为 |
|---|---|
| 默认 | **两个开关都默认关**，`settings.json` 加字段是 `#[serde(default)]`，旧文件零迁移 |
| 门禁 | 任一开关「关 → 开」的边沿 → daemon 强制检查**每个挂载点都已排除出 Baloo 索引**（内容索引器读文件 = 水合，没排除就等于邀请它把整个 NAS 拉到本地）；GUI 预检不过会弹「打开终端，自动添加排除」 |
| 按挂载点 | 每个挂载点独立判定「设置开了 **且** 不会被 Baloo 索引」，一个没排除的点不牵连其它 |
| 热切换 | 开关与 FUSE 共享 `Arc<AtomicBool>`，`settings_save` 后立刻生效，**不用重挂载**；关掉后 xattr 立即 `ENODATA` |
| 重新检测 | `baloo_status`（GUI 的「重新检测 Baloo」/ `qxync baloo-status`）会顺带热刷新挂载点标志 —— 在终端手动排除后点一下即生效 |
| CLI | `qxync state` / `qxync baloo-status` 显示两个开关；直连 `settings --set` 打前置警告 |

## 四、xattr 契约与兼容

新增：`user.qxync.overlay`

| 情况 | 值 |
|---|---|
| 开关开 + 已水合 | `hydrated` |
| 开关开 + 部分缓存 | `partial` |
| 开关开 + 纯占位符 | `placeholder` |
| 开关开 + 目录 | 空串（插件据此不画角标） |
| 开关关 / 挂载点会被索引 | 属性不存在（`getxattr` → `ENODATA`） |

* 状态仍可机读：`user.qxync.state`（placeholder / partial / hydrated）**值没变**；
* `user.xdg.tags` 的值从 `已水合` / `仅在线` / `部分本地` 改成 `✓` / `☁` / `◐`
  （Tags 列只能显示字符，中文词在满屏文件名里不显眼）；**有脚本解析过 tags 的
  需要跟着改**，要稳定语义请用 `user.qxync.state`；
* 老 daemon 不暴露 `user.qxync.overlay` / 不认识 `dolphin_overlay`：插件不画角标，
  本版本之前的行为一字不变（IPC 未知字段忽略）。

## 六、已知边界

* **只支持 KF6 Dolphin**（KDE Plasma 6）；Nautilus / Thunar / Flatpak Dolphin 不做；
* 角标**不在 release 产物里**：插件是独立 CMake 工程（KF6 ABI 与发行版绑定），
  需要 KF6 开发包自己编译（Arch：`qt6-base kio cmake`）；要进发行包得单独打；
* Dolphin **在创建视图时**加载插件，已经开着的窗口不会热加载 —— 重启 Dolphin；
* 详情视图默认 16px 图标 → 角标只有 8px（能认但小）；把图标尺寸调到 22/32px
  会得到 16/22px 角标；
* 插件只认本地 `file://`；状态仍**不实时推送**（F5 / 重进目录刷新）；
* 挂载点上加不了用户自己的标签（`setxattr` 有意不实现），角标/Tags 都是系统生成
  的只读值。

## 七、升级 / 卸载

* 升级：换二进制 + 重启 daemon；设置文件零迁移，两个开关都默认关；
* 不装插件 = 与 v0.7.1 行为一致（只是 Tags 列的值变成了图标字符）；
* 卸载插件：删 `<Qt 插件目录>/kf6/overlayicon/libqxync_overlay.so` 与
  hicolor 下三个 `qxync-*.svg`，重启 Dolphin；关掉开关也能让角标立刻消失。
