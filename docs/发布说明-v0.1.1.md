# qxync v0.1.1 —— 预编译产物 + Arch 包

**中文** · [English](#english)

[![License](https://img.shields.io/badge/license-MIT%20OR%20Apache--2.0-blue.svg)](https://github.com/mlzxgzy/qxync/blob/master/LICENSE-MIT)

**这一版没有改客户端行为。** `v0.1.0..v0.1.1` 之间**没有任何 Rust 代码改动**
（`git diff --stat v0.1.0 HEAD -- '*.rs'` 为空）；改的是「怎么把 qxync 交到用户手里」。

> ⚠️ 只用于**你自己拥有或已获明确授权**的 QNAP NAS。本项目不分发任何 QNAP 二进制、
> 不绕过任何授权或保护措施，与 QNAP Systems, Inc. **无任何关联**。
> 完整条款见 [`DISCLAIMER.md`](https://github.com/mlzxgzy/qxync/blob/master/DISCLAIMER.md)。

## 这一版新增

- **Release 直接带预编译产物**：推 `v*` tag 即由 CI 构建并挂上
  `qxync-0.1.1-x86_64-unknown-linux-gnu.tar.gz`（`qsync` / `qxyncd` / `qxync-gui`
  三个二进制 + 桌面项 / 图标 / 许可证）、三个裸二进制与 `SHA256SUMS`。
  （v0.1.0 的 Release 当时没挂任何产物，以本版为准。）
- **Arch Linux 包（AUR `qxync-bin`）**：`packaging/arch/` 里的 PKGBUILD 直接取上面的
  tar.gz，`makepkg -si` 即可装成系统包；推到 AUR 之后就是 `yay -S qxync-bin`。
- 三个二进制**有意不 strip**：保留 `line-tables-only` 调试信息，用户报 bug 时贴出来的
  回溯才可读 —— 代价是 GUI 二进制约 85 MB、tar.gz 约 52 MB，这是拿体积换可诊断性。

## 安装

| 资产 | 说明 |
|---|---|
| `qxync-0.1.1-x86_64-unknown-linux-gnu.tar.gz` | 三个二进制 + 桌面项 / 图标 + 许可证 / 免责声明 |
| `qsync` · `qxyncd` · `qxync-gui` | 三个裸二进制，同一份构建 |
| `SHA256SUMS` | 校验和（`sha256sum -c SHA256SUMS`） |

解包后三个二进制**放在同一个目录**即可：GUI 先找自己旁边的 `qxyncd`，找不到再退回 `PATH`。
运行 GUI 需要系统里有 WebKitGTK 4.1 / GTK 3 运行时（Debian/Ubuntu：
`libwebkit2gtk-4.1-0` + `libgtk-3-0`），FUSE 3 需要 `/dev/fuse` + `fusermount3`。

```bash
tar xzf qxync-0.1.1-x86_64-unknown-linux-gnu.tar.gz
cd qxync-0.1.1-x86_64-unknown-linux-gnu
./qsync --version        # qsync 0.1.1
./qxync-gui              # 或者把三个文件放进 PATH 里的某个目录
```

**Arch Linux**：仓库里带一份 AUR 用的包定义（`packaging/arch/`，包名 `qxync-bin`），
`makepkg -si` 就装成系统包（带桌面项与图标）；推到 AUR 之后就是 `yay -S qxync-bin`。

也可以从源码构建（可复现、可审计）：

```bash
git clone https://github.com/mlzxgzy/qxync.git
cd qxync
cargo build --workspace --release
```

需要 **Rust 1.90+**；完整依赖、用法与已知限制见
[README](https://github.com/mlzxgzy/qxync/blob/master/README.md)。

## English

# qxync v0.1.1 — prebuilt artifacts + Arch package

**No client behaviour changed in this version.** There are **no Rust code changes** between
`v0.1.0` and `v0.1.1` (`git diff --stat v0.1.0 HEAD -- '*.rs'` is empty) — what changed is *how
qxync reaches users*.

> ⚠️ For QNAP NAS devices **you own or are explicitly authorized to administer** only.
> This project distributes no QNAP binaries and circumvents no authorization or protection
> measure. It is **not affiliated with QNAP Systems, Inc.** See
> [`DISCLAIMER.md`](https://github.com/mlzxgzy/qxync/blob/master/DISCLAIMER.md).

### What's new

- **Prebuilt artifacts on the release itself**: pushing a `v*` tag makes CI build and attach
  `qxync-0.1.1-x86_64-unknown-linux-gnu.tar.gz` (the `qsync` / `qxyncd` / `qxync-gui` binaries
  plus desktop entry / icons / licences), the three binaries on their own, and `SHA256SUMS`.
  (The v0.1.0 release had no assets at all — use this one.)
- **Arch Linux package (AUR `qxync-bin`)**: the PKGBUILD in `packaging/arch/` pulls the tarball
  above; `makepkg -si` installs it as a system package, and once it is on the AUR it is
  `yay -S qxync-bin`.
- The binaries are **intentionally not stripped**, so backtraces stay readable in bug reports —
  the GUI binary is ~85 MB and the tarball ~52 MB. Size traded for diagnosability.

### Install

| Asset | What it is |
|---|---|
| `qxync-0.1.1-x86_64-unknown-linux-gnu.tar.gz` | all three binaries + desktop entry / icons + licences / disclaimer |
| `qsync` · `qxyncd` · `qxync-gui` | the three binaries on their own, from the same build |
| `SHA256SUMS` | checksums (`sha256sum -c SHA256SUMS`) |

Keep the three binaries in the **same directory**: the GUI first looks for `qxyncd` next to
itself and only then falls back to `PATH`. Running the GUI needs the WebKitGTK 4.1 / GTK 3
runtime (`libwebkit2gtk-4.1-0` + `libgtk-3-0` on Debian/Ubuntu); FUSE 3 needs `/dev/fuse` +
`fusermount3`.

```bash
tar xzf qxync-0.1.1-x86_64-unknown-linux-gnu.tar.gz
cd qxync-0.1.1-x86_64-unknown-linux-gnu
./qsync --version        # qsync 0.1.1
./qxync-gui
```

**Arch Linux**: the repo ships an AUR package definition (`packaging/arch/`, package name
`qxync-bin`) — `makepkg -si` installs it as a system package (with a desktop entry and icons);
once published to the AUR it is `yay -S qxync-bin`.

You can also build from source (reproducible and auditable):

```bash
git clone https://github.com/mlzxgzy/qxync.git
cd qxync
cargo build --workspace --release
```

Requires **Rust 1.90+**; see the [README](https://github.com/mlzxgzy/qxync/blob/master/README.en.md)
for the full dependency list, usage and known limitations.
