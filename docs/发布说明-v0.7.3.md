## 一句话

以前下载大文件只能干等：`get` 没有任何反馈，GUI「下载到本地」的徽标也只写
「进行中…」。v0.7.3 给三条路（CLI 直连 / CLI 经 daemon / GUI）都接上进度 ——
**3 秒是静默期**：3 秒内完成的下载一个字都不多打（输出与之前完全一致），
超过 3 秒才在 stderr 原地刷新「百分比 + 进度条 + 已下载/总量 + 速度 + 剩余时间」。
另一头，v0.7.2 的角标插件装没装、装的位置 Dolphin 认不认，以前只能靠肉眼 ——
现在 `qxync baloo-status` 直接告诉你，插件的 Arch 包也从 Release 一条命令装。

## 〇、怎么用（都不用开开关）

```text
下载进度：全自动，无开关。
  CLI   ：qxync get NAS:/大文件 ./          # stderr 是终端就有进度
  GUI   ：文件页 → 下载到本地                # 「进行中…」徽标上直接亮进度
  重定向：qxync get NAS:/大文件 ./ > log    # 进度自动消失，log 保持纯净

角标插件检测：
  qxync baloo-status                        # 多一行「角标插件 : …」
  GUI 设置 → 高级                            # 检测表多一行

Arch 用户装角标插件（KF6 Dolphin）：
  从本 Release 下载 qxync-dolphin-overlay-0.7.3-1-x86_64.pkg.tar.zst
  sudo pacman -U qxync-dolphin-overlay-0.7.3-1-x86_64.pkg.tar.zst
  重启 Dolphin（插件只在建视图时加载）
```

## 一、下载进度：3 秒静默期（M26）

用户目标原话：「文件下载时间超过 3 秒就显示下载进度和速度」。设计取舍：

| 方面 | 行为 |
|---|---|
| 静默期 | 下载 **3 秒内**完成 → 输出与之前**逐字节一致**（快下载零打扰） |
| 超过 3 秒 | stderr **原地刷新**一行：`百分比 + 进度条 + 已下载/总量 + 速度（3 秒滑窗）+ 剩余时间`，10 Hz 节流 |
| 写 stderr | stdout 保持纯净，`qxync get > log` 不混进度 |
| 非终端 | stderr 重定向/管道 → CLI 不声明、daemon 不建通道不推行，日志干净 |
| 未知总量 | 服务端 chunked（无 Content-Length）→ 退化为「已下载 + 速度」；CLI 直连另用 `stat` 的远端大小兜底 |

### 三条路怎么接的

| 路 | 机制 |
|---|---|
| CLI 直连 | 客户端分片回调喂 `DownloadProgress`（新 `progress.rs`） |
| CLI 经 daemon | 请求信封带 `progress:true` **能力声明** → daemon 在下载期间往**同一条 socket** 推进度行（10 Hz 节流 + `try_send`，通道满了就丢，**绝不阻塞下载循环**）；超时**按行重置**（有进度流动就不掐 600s 总闸） |
| GUI「下载到本地」 | `ipc_call_with_progress` 命令 + `progress://download` 事件，进度亮在文件页「进行中…」徽标上（**不弹窗挡操作**） |

### 兼容矩阵（新旧混搭都安全）

| 组合 | 行为 |
|---|---|
| 新 CLI + 新 daemon | 全功能 |
| **老 CLI** + 新 daemon | 不声明 `progress` → daemon 一个进度行都不发，行为与之前一字不变 |
| 新 CLI + **老 daemon** | serde 宽容忽略未知信封字段，读循环直接收最终响应（安全退化，只是没进度） |
| 新 GUI + 老 daemon | 徽标保持原样 |
| stderr 非终端 | 任何组合都不画 |

## 二、角标插件安装检测（M25）

v0.7.2 装完插件不显示角标时，排查全靠肉眼（真机就踩过：装在 `~/.local` 但
`QT_PLUGIN_PATH` 没包含 → Dolphin 根本不加载）。v0.7.3 主程序直接回答
「角标到底会不会显示」：

| 检测结果 | baloo-status 显示 |
|---|---|
| 系统目录已装 | `角标插件 : 已安装（/usr/lib/qt6/plugins/kf6/overlayicon/libqxync_overlay.so）` |
| 装在 `~/.local` 且 `QT_PLUGIN_PATH` 包含 | 已安装（路径） |
| 装在 `~/.local` 但环境变量没包含 | 装了但 **Dolphin 不会加载**（附建议：系统级安装） |
| 未安装 | 未安装 + 装法提示 |

* 检测规则与 **Qt 的插件查找顺序对齐**：`QT_PLUGIN_PATH` → 系统目录（覆盖
  Arch / openSUSE / Debian 常见路径）→ `~/.local`；
* CLI 侧是**本地文件检查，不依赖 daemon 版本**（对还在跑的老 daemon 照答）；
* GUI 设置 → 高级的检测表同步显示；老 daemon 不发 `overlay_plugin` 字段就不
  显示该行（不误报「未安装」）；
* 检测只提示不拦开关（xattr 本身无害）。

## 三、角标插件的 Arch 包：Release 分发（M25）

插件是 KF6 C++ 工程（ABI 与发行版绑定），不能塞进 `qxync-bin`。本版起发版
流水线直接产出 **`qxync-dolphin-overlay-<版本>-1-x86_64.pkg.tar.zst`**：

* 在 `archlinux:base-devel` 容器里对着**当次 tag 的源码归档**现编 —— 与
  `packaging/arch-dolphin-overlay/PKGBUILD`（AUR 包定义）**同一份配方**，
  CI 每次发版替用户先验一遍；
* 包内容逐项校验（`.so` + 三个 SVG）后才挂 Release；
* `pacman -U` 安装，卸载即删两处文件（插件目录 + 图标）；
* AUR 账号注册好之后，同一份 PKGBUILD 原样推 AUR（`yay -S` 即装）。

## 六、已知边界

* **进度只覆盖 `get`（下载）**：`put` 上行走的是 FUSE 上传队列（有独立的任务
  状态视图），本版未接进度行；
* GUI 真窗口（Tauri + WebKit）截图未拍 —— 本环境无显示；JS 侧以源文本级测试
  + `node --check` 覆盖，Rust 侧 `ipc_call_with_progress` 以假 daemon 单测覆盖；
* 服务端 chunked（无 Content-Length）的**真机**形态未验 —— mock 全带
  Content-Length；未知总量路径由单测覆盖；
* 角标插件仍**只支持 KF6 Dolphin**（KDE Plasma 6）；Nautilus / Thunar /
  Flatpak Dolphin 不做；Dolphin 在创建视图时加载插件，装完要重启 Dolphin；
* CI 的「打 Dolphin 角标插件包」步骤**本次发版第一次真跑** —— 本地已用同一
  PKGBUILD + 本机 KF6 实打过包，容器步骤与 `qxync-bin` 的 Arch 打包同构；
* AUR 推送（`qxync-bin` / `qxync-dolphin-overlay`）仍等账号注册（SSH 公钥
  未加），仓库里的包定义已就绪。

## 七、升级 / 卸载

* 升级：换二进制 + 重启 daemon；设置文件零迁移；
* 经 daemon 的下载进度需要新 daemon（老 daemon 下直连路径仍有进度，经 daemon
  安全退化为无进度）；
* 角标插件包：`pacman -R qxync-dolphin-overlay` 卸载（或手动删
  `<Qt 插件目录>/kf6/overlayicon/libqxync_overlay.so` 与 hicolor 下三个
  `qxync-*.svg`），重启 Dolphin；关掉 `dolphin_overlay` 开关也能让角标立刻
  消失。
