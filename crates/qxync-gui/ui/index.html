    冲突策略（Conflict policies）

    策略挂在**任务**上（不是全局）。没配过的任务默认 rename_local，也就是 M2c 一直以来的行为 「远端占原名、本地内容另存 xxx (conflicted copy from …)」。 replace_* 两个选项会**丢一边的改动**，界面上有显式警告。

    每个任务的策略在「任务」页的**文件夹对设置**里改； 「每个文件都问我」的待裁决项也在任务页顶部处理。

    LAN 加速（LAN sync）

    qxync 的 LAN 通道是**自研协议**（与官方 Windows 客户端的 LAN 二进制通道不互通，已决策不做）。 它的作用是：同一账号的另一台 qxync 设备上已有内容时，水合优先走局域网直传，失败自动回落 NAS。 默认**不监听**（要显式打开）；配对用的是明文 TCP + 共享令牌，只在可信局域网里用。

    监听地址改动要**重启 daemon** 才生效（保存后可以在「诊断 → 挂载」里停止再启动）。
